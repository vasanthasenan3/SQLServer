# SQL Server Practice

This repository contains my SQL Server practice queries and examples, covering SQL commands, constraints, aggregate functions, subqueries, joins, and stored procedures.

## 📚 Topics Covered

### 1. SQL Commands

* DDL (Data Definition Language)
* DML (Data Manipulation Language)
* DQL (Data Query Language)
* DCL (Data Control Language)
* TCL (Transaction Control Language)

### 2. SQL Constraints

* PRIMARY KEY
* NOT NULL
* UNIQUE
* CHECK
* DEFAULT
* IDENTITY
* Identity Functions:

  * `IDENT_CURRENT()`
  * `@@IDENTITY`
  * `SCOPE_IDENTITY()`
  * `IDENT_SEED()`
  * `IDENT_INCR()`

### 3. Aggregate Functions

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`
* `GROUP BY`
* `HAVING`
* `COUNT(DISTINCT)`

### 4. Subqueries

* Subqueries with aggregate functions
* Finding employees with salaries above the average
* Finding the highest, second-highest, and lowest salaries
* Comparing employee salaries
* Retrieving employees from the same department
* Using `ORDER BY` with `ASC` and `DESC`

### 5. Joins

* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* `FULL OUTER JOIN`
* `CROSS JOIN`

### 6. Stored Procedures

* Creating Stored Procedures using `CREATE PROCEDURE`
* Modifying Stored Procedures using `ALTER PROCEDURE`
* Retrieving all product records
* Retrieving products using input parameters
* Updating product names
* Updating stock values using `IF-ELSE` conditions
* Executing Stored Procedures using `EXEC`

## 🛠️ Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

## 🎯 Purpose

The purpose of this repository is to strengthen my SQL Server fundamentals through hands-on practice, understand commonly used SQL concepts, and improve my database querying skills.
